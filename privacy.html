プライバシーポリシー

制定日 2026-10-24

YMM Lab（以下「当事業」）が作る業務ツール「voicenotes-pipeline」での、Googleアカウントのデータの扱いを定めます。

1. このツールについて

voicenotes-pipelineは、当事業の運営者が自分のパソコンで使うための個人用ツールです。運営者自身のボイスメモから拾ったTODOを、運営者自身のGoogle Tasksに登録します。運営者以外の人は利用しません。

2. 使うGoogleのデータ

  • 使う権限は、Google Tasks（https://www.googleapis.com/auth/tasks）だけです。
  • TODOの追加と、まちがえて登録したTODOの削除だけに使います。
  • メール、連絡先、ファイルなど、Google Tasks以外のデータは読み取りません。

3. データの保存と共有

  • Googleとのやり取りに使う認証情報は、運営者のパソコンの中にだけ保存します。
  • Googleから受け取ったデータを、第三者に売ったり、渡したり、広告に使ったりしません。
  • 当事業のサーバーへデータを送ることはありません（当事業はそのためのサーバーを持っていません）。

Google APIから受け取った情報の利用と他のアプリへの転送は、Google API Services User Data Policy（限定使用の要件を含む）に従います。

4. 権限の取り消し

Googleアカウントの「サードパーティ製のアプリとサービス」から、いつでもこのツールの権限を取り消せます。

5. 変更とお問い合わせ

このポリシーを変更するときは、このページを更新します。お問い合わせは info@ymmlab.com まで。

ENGLISH SUMMARY

voicenotes-pipeline is a personal tool used only by the operator of YMM Lab. It uses the Google Tasks scope solely to add and delete the operator's own tasks. Credentials are stored only on the operator's computer. No Google user data is sold, shared, transferred to third parties, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Contact: info@ymmlab.com
